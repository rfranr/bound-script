# Assignment 0018 — Two Independent Boxes

## Goal

Demonstrate that two independently generated TypeScript Boxes can be verified and composed without exposing either implementation to the other agent.

BoundScript controls architectural boundaries, not application logic or orchestration.

## Experiment

- **NormalizeContact** exposes a human-owned public contract for normalizing contact data.
- **RenderWelcome** consumes NormalizeContact through its explicitly authorized public contract and produces a welcome message.
- Each Box is implemented by a separate, fresh Pi agent session in an isolated workspace.
- Ordinary TypeScript application code composes the two accepted artifacts.

Choose the smallest useful input/output contracts before generation. The dependency must be real and exercised in the integration test, not merely declared.

## Requirements

1. Human-owned tasks, public contracts, dependency permissions, and acceptance checks are not writable by agents.
2. Each agent can read its own task and public contract, plus only the public contracts of explicitly authorized dependencies. The RenderWelcome agent must not receive NormalizeContact's implementation.
3. Both candidates are generated by real Pi sessions, independently verified, and promoted only on success.
4. A separate integration step composes the *unchanged* accepted artifacts using ordinary TypeScript and runs end-to-end tests.
5. Include at least one deliberate unauthorized dependency/access attempt and show that it is rejected by a real control. Distinguish filesystem denial from source-import restrictions; do not claim stronger enforcement than demonstrated.
6. Record actual tool runs, tests, failures, and remaining limitations. Do not expose credentials or raw agent transcripts containing secrets.

## Constraints

Extend the existing `experiments/minimal-box` reference rather than introducing a framework. No DSL, Director, custom application runtime, generic artifact registry, plugin system, or speculative multi-language support.

Choose the simplest explicit dependency declaration that works; do not assume YAML or a new manifest format is necessary. Keep the existing prototype credential/network risks explicit and do not silently broaden permissions.

## Acceptance

A fresh run independently generates and verifies both Boxes, then integrates them without hand-editing agent output. End-to-end behavior passes. At least one negative boundary test fails as intended, and the report states exactly what was enforced and what was not.

Make focused commits on `experiment/boundscript-next`. Do not modify `feature/agent-driven-architecture`. Report commands, results, commit SHAs, and any deviations.
