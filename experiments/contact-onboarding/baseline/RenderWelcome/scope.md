# Scope

Own only message/suppression decisions from the supplied record, not normalization or revalidation.

Submit complete `.ts` files under `candidate/**` only, starting from the seed. Private helpers/tests are allowed there. No `.d.ts`, manifest, lockfile, config, symlink, resource or new public entrypoint. No new dependency. Keep interfaces/responsibilities unchanged. Ask the human about conflicting/missing intent; do not seek peer context. See shared policy.
